# @stock-tracker/subgraph-auth

## 0.1.0

### Minor Changes

- [#340](https://github.com/aramiworks/stock-tracker/pull/340) [`0ae800a`](https://github.com/aramiworks/stock-tracker/commit/0ae800a43d2346457fcf8040210bac46eb746e75) Thanks [@cheunjm](https://github.com/cheunjm)! - Split the single Apollo subgraph into two domain-aligned subgraphs: `subgraph-auth` (User entity, identity, port 4002 prod / 4013 dev) and `subgraph-tracker` (Account, Purchase, port 4001 prod / 4011 dev). Each is independently buildable, deployable, and publishable to the Apollo registry. Cross-domain `User` references continue to work via the existing `@key(fields: "id")` federation entity.
