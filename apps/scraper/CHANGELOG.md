# @stock-tracker/scraper

## 0.1.0

### Minor Changes

- [#439](https://github.com/aramiworks/stock-tracker/pull/439) [`fc5d9fe`](https://github.com/aramiworks/stock-tracker/commit/fc5d9feaa7013f9a3ef2a3879af156e8f331337f) Thanks [@cheunjm](https://github.com/cheunjm)! - Add scraper observability: parse-error reporter (persists to `parse_errors` and emits structured logs), Better Stack metrics (reuses `packages/config` Pino + Logtail), and Slack pager that fires once per SKU after 5 consecutive failures with a 6h cooldown. New `sku_stock_state.last_paged_at` column drives the cooldown dedupe.

  New env: `BETTER_STACK_TOKEN`, `BETTER_STACK_INGEST_HOST`, `SLACK_PAGER_WEBHOOK_URL`, `SLACK_PAGE_FAILURE_THRESHOLD`.

### Patch Changes

- [#394](https://github.com/aramiworks/stock-tracker/pull/394) [`6c803ed`](https://github.com/aramiworks/stock-tracker/commit/6c803ed0bc45e2484eaf899b7892683938fc0984) Thanks [@cheunjm](https://github.com/cheunjm)! - Add standalone smoke-test runner and record live HTTP vs Browser bake-test results.

- [#381](https://github.com/aramiworks/stock-tracker/pull/381) [`8fd8010`](https://github.com/aramiworks/stock-tracker/commit/8fd8010aca4b2111fb0d0df0c57fb5f6aa78e2fb) Thanks [@cheunjm](https://github.com/cheunjm)! - Add BrandAdapter and Fetcher interfaces with Hermès adapter scaffold, proxy helpers, state buffer, and ingest client stub.

- [#415](https://github.com/aramiworks/stock-tracker/pull/415) [`30f4062`](https://github.com/aramiworks/stock-tracker/commit/30f4062bdc63ef652ba669cb22e6d35ab6e7d07a) Thanks [@cheunjm](https://github.com/cheunjm)! - Spike INF-1507: identify Hermès KR anti-bot as DataDome + Cloudflare (not Akamai), validate a CapSolver DataDome solve end-to-end, and add a `CapSolverDatadomeFetcher` that detects the 403 interstitial and solves it on the same sticky exit IP. Bake test shows plain HTTP is reliably clean on live product URLs, with intermittent IP-bound interstitials the solver rescues.

- [#434](https://github.com/aramiworks/stock-tracker/pull/434) [`62b07ad`](https://github.com/aramiworks/stock-tracker/commit/62b07ad684abee628fd782f9dfb0b691780ada1e) Thanks [@cheunjm](https://github.com/cheunjm)! - Wire the real tRPC ingest client: `createIngestClient` now calls tracker-service's `tracker.ingest.dropEvent.upsert` over httpBatchLink + superjson, authenticating with the `X-Service-Token` header. `pollCartierTask` passes it (when `TRACKER_INGEST_URL` + `TRACKER_INGEST_SERVICE_TOKEN` are set), so a Cartier out→in transition now creates drop events and alerts; without the env it records + logs only.

- [#414](https://github.com/aramiworks/stock-tracker/pull/414) [`8a9b55e`](https://github.com/aramiworks/stock-tracker/commit/8a9b55e3cf51dd32eeb34065129056cd150fbdeb) Thanks [@cheunjm](https://github.com/cheunjm)! - Wire Cartier into a scheduled pollCartier task: enumerate active Cartier SKUs, fetch + parse stock via the adapter (no proxy), and record state transitions. Make Fetcher.proxy optional so fingerprint-level brands fetch without a proxy. Drop-event ingest is gated behind the stubbed tRPC client until INF-1356 lands.

- [#409](https://github.com/aramiworks/stock-tracker/pull/409) [`fad4b6c`](https://github.com/aramiworks/stock-tracker/commit/fad4b6c1e6a8939baf4696b210ea3012acbee1cd) Thanks [@cheunjm](https://github.com/cheunjm)! - Add Cartier KR scraper adapter with a working parser (online stock keyed on the add-button `hidden` toggle), registered in the brand registry.

- [#428](https://github.com/aramiworks/stock-tracker/pull/428) [`fb245a9`](https://github.com/aramiworks/stock-tracker/commit/fb245a952cd1b3934fba4e6864faadd0b3b066de) Thanks [@cheunjm](https://github.com/cheunjm)! - Add a nullable `skus.source_url` so Cartier watches whose PDP URL isn't derivable from the reference code (Santos/Panthère/Ballon Bleu/Tank Américaine) can be polled. `SkuRef.url` and `CartierAdapter.buildUrl` use the stored URL when present, falling back to the Tank Must pattern; `pollCartier` selects and passes `source_url`. Seed expanded with representative non-Tank-Must watches.

- [#385](https://github.com/aramiworks/stock-tracker/pull/385) [`7da14fc`](https://github.com/aramiworks/stock-tracker/commit/7da14fca32c5f2df4f14bf6287ed0c42daac270f) Thanks [@cheunjm](https://github.com/cheunjm)! - Add HttpFetcher (got-scraping) and BrowserFetcher (Playwright+stealth) implementations with bake-test harness for comparing success rates against Akamai Bot Manager on hermes.com/kr.

- [#425](https://github.com/aramiworks/stock-tracker/pull/425) [`ed6bfcc`](https://github.com/aramiworks/stock-tracker/commit/ed6bfccb7cc441ea65c41f95eb0a58d22270e719) Thanks [@cheunjm](https://github.com/cheunjm)! - Add the Hermès poll vertical slice: a composite HermesFetcher (free Oxylabs KR sticky-IP rotation with an off-by-default CapSolver fallback), a pollHermes task mirroring pollCartier, and a poll-hermes schedule.

- [#402](https://github.com/aramiworks/stock-tracker/pull/402) [`3082908`](https://github.com/aramiworks/stock-tracker/commit/3082908fdc670304100bebaae7f997dcef00a942) Thanks [@cheunjm](https://github.com/cheunjm)! - Add OxylabsScraperApiFetcher behind the Fetcher interface and WSA smoke runner for INF-1492 bake test.

- [#445](https://github.com/aramiworks/stock-tracker/pull/445) [`ea7ea25`](https://github.com/aramiworks/stock-tracker/commit/ea7ea2591e3be6e276ce1e43b209f6449c3e2862) Thanks [@cheunjm](https://github.com/cheunjm)! - Add a daily Hermès live-URL discovery job: sweep the women's-bags category, record each live product in a new `discovered_products` freshness table (idempotent on article code), and mark entries stale after a 14-day TTL.

- [#441](https://github.com/aramiworks/stock-tracker/pull/441) [`adb8a65`](https://github.com/aramiworks/stock-tracker/commit/adb8a6552c82b6e5f592d55713e4e20ab30963d7) Thanks [@cheunjm](https://github.com/cheunjm)! - Harden the Hermès read path: force HTTP/1.1 on the proxied GETs so DataDome challenges are parseable, implement the JSON-LD availability parser, and env-gate the inline CapSolver solve into the Hermès poll task.

- [#448](https://github.com/aramiworks/stock-tracker/pull/448) [`e14831f`](https://github.com/aramiworks/stock-tracker/commit/e14831f288a0ddaba7de37f2fdee86236c5c0683) Thanks [@cheunjm](https://github.com/cheunjm)! - Add a Hermès discovered-products availability monitor: a scheduled job resolves each non-stale `discovered_products` bag's stock through the hardened read path and stores `in_stock`/`last_checked_at`/`last_changed_at` on the row, so "what's in stock now" is a DB query. Decoupled from the curated catalog and alert pipeline.

- [#377](https://github.com/aramiworks/stock-tracker/pull/377) [`c644345`](https://github.com/aramiworks/stock-tracker/commit/c644345ddba04e285d1e0d7b8a63da1ddc45c758) Thanks [@cheunjm](https://github.com/cheunjm)! - Scaffold apps/scraper Trigger.dev v3 project with Dockerfile and Doppler wiring.

- [#444](https://github.com/aramiworks/stock-tracker/pull/444) [`30e53b8`](https://github.com/aramiworks/stock-tracker/commit/30e53b81482710eb03dd792e6908a1f51feaffc0) Thanks [@cheunjm](https://github.com/cheunjm)! - Sync the deployed scraper's env from Doppler at deploy time via a `syncEnvVars` build extension (pulls the config the deploy's `DOPPLER_TOKEN` is scoped to), making Doppler the single source of truth for Trigger.dev env — including `TRACKER_INGEST_SERVICE_TOKEN` + `TRACKER_INGEST_URL`. Also adds the now-required `maxDuration` config option.
